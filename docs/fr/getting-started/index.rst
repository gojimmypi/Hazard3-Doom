Prise en main
=============

Cette section décrit les chemins les plus courts depuis des images précompilées ou un nouveau checkout jusqu'à un système Hazard3-Doom en fonctionnement.

Sous Windows, utilisez **WSL avec Ubuntu** pour tout build depuis les sources et
pour les scripts shell du dépôt. Sauf lorsqu'un bloc est explicitement marqué
PowerShell ou ``cmd.exe``, exécutez les commandes Windows dans WSL/Bash. Le
chemin sans installation dans le navigateur est l'exception et ne nécessite
pas WSL.
