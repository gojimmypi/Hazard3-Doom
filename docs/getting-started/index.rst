Getting Started
===============

This section covers the shortest paths from prebuilt images or a fresh source checkout to a running Hazard3-Doom system.

On Windows, use **WSL with Ubuntu** for every build-from-source or repository
shell-script workflow. Unless a command block is explicitly labeled PowerShell
or ``cmd.exe``, Windows users should run it from WSL/Bash. The browser-only
no-install path is the exception and does not require WSL.
