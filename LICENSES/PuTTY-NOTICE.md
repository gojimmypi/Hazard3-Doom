# PuTTY notice

Hazard3-Doom documentation identifies a bundled `bin/putty.exe` used as a
Windows serial terminal.

Official project:
https://www.chiark.greenend.org.uk/~sgtatham/putty/

license. The official PuTTY licence contains a version-specific copyright
roster that must remain with redistributed copies.

replacement for the exact notice.
