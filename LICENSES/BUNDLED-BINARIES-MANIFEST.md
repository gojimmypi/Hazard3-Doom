## Release rule

Do not publish a release archive containing an item in this table until its
exact version/provenance and the license/source materials required by that
version have been captured. Prefer a machine-readable checksum manifest in the
same release.

If these convenience binaries are removed from releases and users are instead
directed to upstream download pages, this table can be reduced accordingly.
