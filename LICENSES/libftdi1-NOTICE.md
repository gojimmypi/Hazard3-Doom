# libftdi1 notice

Hazard3-Doom documentation identifies a redistributed `bin/libftdi1.dll`.

Upstream:
https://www.intra2net.com/en/developer/libftdi/

libftdi is developed by Intra2net AG and the libftdi developer community;
Thomas Jarosch is a long-time maintainer. Current upstream source identifies the
main C library as LGPL-2.1-only. In January 2026 the project explicitly
clarified that this had been the intended/source-header license since the
initial library commit, while other tools/wrappers in the source distribution
can use different GPL terms.

Before release, identify the exact DLL version and SHA-256 and retain the
matching upstream `LICENSE`, `COPYING.LIB`, source location, and dependency
notices. Do not infer the license of every libftdi source-tree utility from the
DLL's library license.

See `LGPL-2.1.txt` for the relevant LGPL version text.
