# Zadig / libwdi notice

Hazard3-Doom documentation identifies a bundled `bin/zadig-2.5.exe` for Windows
USB driver installation.

Upstream:
https://github.com/pbatard/libwdi
https://zadig.akeo.ie/

Zadig is authored/maintained by Pete Batard / Akeo and current upstream source
identifies Zadig as GPL-3.0-or-later. Its libwdi component is identified as
LGPL-3.0-or-later. Upstream also carries additional third-party notices,
including configuration parsing work credited to Theodore Ts'o and the
Kerberos Team, USB-ID data credited to Stephen J. Gowdy and contributors, and
dialog inspiration credited to Martin Prikryl / WinSCP.

Because the bundled filename explicitly indicates Zadig 2.5, preserve the
license/about notices from that exact 2.5 source/binary release rather than
substituting only current upstream notices. Record the executable SHA-256 and
make the corresponding source available as required by its GPL terms.

Reference copies of GPL-3.0 and LGPL-3.0 are included in this directory.
